# DRipACS – Teleradiology

DRipACS is a web-based DICOM and teleradiology project designed for viewing and securely sharing authorized medical imaging studies.

## Features

- DICOM medical image viewing
- Teleradiology workflow support
- Secure study sharing
- Patient/study information display
- Web-based access
- Desktop and mobile friendly interface
- Cloud-based access through a secure tunnel
- Designed for authorized medical imaging workflows

## Technology

- HTML / CSS / JavaScript
- DICOM
- GitHub Pages
- Cloudflare Tunnel
- DICOM-compatible imaging workflow

## Website

https://dripacs.is-a.dev

## Purpose

DRipACS is developed as a non-commercial software development project for medical imaging, DICOM viewing, teleradiology workflow testing, and authorized study sharing.

## Important Notice

DRipACS is intended only for authorized medical imaging use.

Users are responsible for ensuring that patient information and medical imaging data are handled securely and in accordance with applicable privacy, security, and healthcare requirements.

This project is not a substitute for professional medical diagnosis or clinical decision-making.
